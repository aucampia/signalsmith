# Security Policy

signalsmith is a personal project maintained in my spare time. If you find a
security issue (for example, something related to how GitHub auth tokens are
read or stored — see [doc/config.md](./doc/config.md#authentication)),
please report it privately rather than opening a public issue:

- Use
  [GitHub Security Advisories](https://github.com/aucampia/signalsmith/security/advisories/new)
  for this repository, or
- Email <aucampia@gmail.com>

I'll do my best to respond, but there's no guaranteed response time or fix
timeline given this is a personal project.
